# Archive: the documents of version 1

These are the planning documents of the first RigReady (January and February 2026, versions 1.0 and 1.1). They are kept as history and are not maintained.

Nothing here describes version 2. Where a document says a feature is "Active", "Complete" or "Planned", that was its state in early 2026 and says nothing about the app today. File names, folders and commands in these documents refer to the version 1 code, which version 2 replaced. A few of its files are kept under `src/legacy/` as reference and are not compiled.

- What the product is: [`docs/PRODUCT.md`](../PRODUCT.md)
- How it is put together: [`docs/ARCHITECTURE.md`](../ARCHITECTURE.md)
- How to use it: the manual, [`docs/manual/`](../manual/index.md)
- Every requirement with its status and evidence: [`docs/requirements/ledger.yaml`](../requirements/ledger.yaml)
