RigReady works with AI in two separate ways. Both are off until you turn them on, and neither is needed for anything else in the app.

- **AI help in the binding guide.** Under **Configure > Binding guide**, RigReady itself asks Claude for a binding plan or answers a question about a DCS aircraft (this help is for DCS only), with an Anthropic API key of your own and what is sent shown first. See [Binding guide and AI help](../dcs/binding-guide-and-ai.md).
- **An assistant of your own, through MCP.** An AI assistant you already use on this PC (Claude Desktop, Claude Code, Cursor, VS Code and others that speak the Model Context Protocol) can use RigReady: check the rig, make it ready, read and change bindings with a preview, apply a monitor layout, make a backup, read the log, and read this manual. RigReady does not pay for it and never hands it your API key.
